# CV bullets — use only after validating the project

**API Quality Engineering Lab — Projeto Pessoal**
- Desenvolvi uma suíte de testes automatizados de API utilizando Java, RestAssured e JUnit 5, cobrindo cenários positivos e negativos de CRUD.
- Validei autenticação por API key, códigos HTTP, headers, bodies JSON, paginação, regras de validação, conflitos e persistência em banco relacional H2.
- Implementei validação de contrato com JSON Schema e integração dos resultados com Allure.
- Criei coleção Postman para testes manuais/exploratórios e documentação de plano de testes, casos de teste e matriz de rastreabilidade.
- Configurei CI com GitHub Actions para execução automatizada da suíte e upload de evidências.

**Tecnologias:** Java, RestAssured, JUnit 5, Spring Boot, H2, JSON Schema, Postman, Maven, Allure, GitHub Actions.
